# Krok 2 – Implementační plán

Stav: **NÁVRH – čeká na schválení (krok 3)**

Každý přírůstek je samostatně spustitelný a ověřitelný. Po každém: automatické testy v CI → tvůj ruční test → commit.

## Krok 4 (před přírůstky) – Repo + CI + prázdná kostra

- Soukromé GitHub repo `portfolio-tracker`, `.gitignore` (bez osobních dat? – viz otázka níže).
- Kostra electron-vite + React + TS, ESLint, Prettier, Vitest s jedním vzorovým testem.
- GitHub Actions na `windows-latest`: `lint` → `typecheck` → `test` → `build`.
- **Ověření:** zelený běh CI na GitHubu; `npm run dev` otevře prázdné okno.
